### Hi, I'm Arthur

Dir of Product at [Iron](https://iron.xyz) (acquired by [MoonPay](https://moonpay.com)), in Berlin. I build the tools I actually use.

Most of my building is a personal agent OS: a handful of agents on one small VPS that coach my Ironman training, file my voice notes, grow my knowledge base while I sleep, and text me when something breaks. It's been running unattended since early 2026.

#### What's here

- **[tri-coach](https://github.com/Arthurpfz/tri-coach)** — AI triathlon coach. Grades every workout against the week's plan, writes next week's on Sunday. n8n + Claude + Intervals.icu.
- **[tricoach-db](https://github.com/Arthurpfz/tricoach-db)** — 250 lines of Express over SQLite that replaced a $30/month Airtable base.
- **[vault-system-template](https://github.com/Arthurpfz/vault-system-template)** — architecture for an Obsidian vault that ingests itself. Bots capture, agents query, it grows on a cron.
- **[text-polisher](https://github.com/Arthurpfz/text-polisher)** — system-wide hotkey that rewrites selected text via Claude. Select, press, done.
- **[PortfolioWebsite](https://github.com/Arthurpfz/PortfolioWebsite)** — [arthurpfz.com](https://arthurpfz.com), where I write the builds up. Astro + Tailwind on Netlify.
